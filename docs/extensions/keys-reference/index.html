    Key name reference¶

    This page lists every key name that keys knows, taken from mdx_steroids/keymap_db.py ("English US keymap, revised 2019-11-18 by Adam Twardoch"). Write a name between ++ and ++, for example ++page-up++.

    • Key name is what you type. It also becomes the CSS class key-<name>.
    • Displayed text is the text inside the <kbd> element.

    Names are matched in lower case, so ++Ctrl++ and ++CTRL++ work. With camel_case: true, ++PageUp++ is read as ++page-up++. Use the key_map option to add names or change the displayed text.

    Note

    The display texts of mac and win contain HTML (<sup>M</sup>, <sup>W</sup>). The extension writes them as text, so the page shows the tags literally, for example &lt;sup&gt;M&lt;/sup&gt; in the HTML source.
